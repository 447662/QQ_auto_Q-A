# 全网电商比价 / E-commerce Price Comparison

## 项目全局 AI 自动回复门禁

在本项目的 QQ、QQ群、QQ 频道、帖子、评论、私信或其他外部消息自动问答场景中，本技能只能作为通过 `#配置推荐` 门禁后的电脑配置推荐辅助能力使用。

- 未包含明确启动口令 `#配置推荐` 时，不要检索、比价或回答，直接返回：`该功能尚未实现，请询问群主或者管理员`。
- 包含口令但问题不是电脑配置相关时，也直接返回同一句兜底文本。
- 不得因为用户只发了商品名、商品链接、平台名、优惠券或价格问题，就绕过门禁触发 AI 自动回答。

本技能整合原 `taobao`（maishou 买手）和 `taobao-shop-price` 两个 skill，用于中国电商平台商品搜索、全网比价、优惠券查询、购买链接获取和购买建议输出。

优先使用 `scripts/price.py`：该脚本仅依赖 Python 标准库，不读写本地文件，只作为客户端请求第三方网站 `maishou88.com` 的商品和价格数据。

| --- | --- |
| 0 | 全部 |
| 1 | 淘宝/天猫 |
| 2 | 京东 |
| 3 | 拼多多 |
| 4 | 苏宁 |
| 5 | 唯品会 |
| 6 | 考拉 |
| 7 | 抖音 |

| 22 | 1688 |

兼容原 `taobao` skill 的平台语义：`source=0` 全部、`source=1` 淘宝/天猫、`source=2` 京东、`source=3` 拼多多、`source=4` 苏宁、`source=5` 唯品会、`source=6` 考拉、`source=7` 抖音、`source=8` 快手、`source=10` 表示 1688。使用 `price.py` 时，1688 请转换为 `sourceType=22`。

## 触发场景

当用户提出以下需求时使用本技能：

- 搜索商品或指定平台商品，例如“帮我从京东检索 AirPods Pro”。
- 比较多个平台价格，例如“帮我比价 iPhone 16 Pro”。
- 寻找最低价、优惠券、折扣、购买链接或口令。
- 做购物调研、批量采购前的价格参考。
- 用户询问“这个商品哪里买便宜”“能不能帮我找购买链接”。

## 工作流程

### 第一步：构造关键字并检索

从用户输入中提取核心商品关键词，默认执行全平台搜索：

```bash
python3 scripts/price.py search --keyword "关键字" --sourceType 0 --pages 1 --format csv
```

可选参数：

- `--sourceType`：平台编码，默认 `0` 全部。
- `--pages`：页码，支持 `1` 或 `1,2,3`。
- `--sort price`：按实际价格排序。
- `--format csv|markdown`：默认 `csv`，便于后续解析。

如果用户明确指定平台，按平台设置 `sourceType`。如果用户想看更多结果，可增加 `--pages`。

### 第二步：过滤无关商品并输出推荐表格

从检索结果中逐条检查商品名称：

- 保留名称、规格、型号、品类与用户需求明确相关的条目。
- 排除明显不相关、配件冒充主商品、规格不符或品类不符的条目。
- 注意同义词、别名和规格差异，例如“纸尿裤”和“拉拉裤”、不同容量/颜色/套装。

过滤后输出 Markdown 表格，列名固定为：

| ID | 名称 | 平台 | 商铺 | 价格 | 原价 | 优惠 | 月销 | 推荐度 | 推荐理由 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |

说明：

- `ID`：从 1 开始的展示序号，供用户后续选择。
- `名称`：商品标题，过长时保留关键信息。
- `平台`：根据 `sourceType` 映射平台名。
- `价格`：`actualPrice`。
- `原价`：`originalPrice`，与现价相同或为空可标 `-`。
- `优惠`：`couponPrice`，无优惠标 `-`。
- `月销`：`monthSales`。
- `推荐度`：综合相关性、价格、月销评为 1-5 星。
- `推荐理由`：一句话说明推荐或谨慎原因。

推荐度评估优先级：

1. 相关性：是否准确匹配用户要买的商品。
2. 价格：同类商品中是否有竞争力。
3. 月销量：销量越高通常可信度越高。
4. 店铺和优惠：有优惠但价格、销量或相关性异常时需提示风险。

按推荐度从高到低排列；推荐度相同按价格升序排列。

必须在内部保留映射：`展示 ID -> goodsId + sourceType + 商品原始信息`。不要在推荐表格中展示 `goodsId`，但后续获取链接必须使用。

### 第三步：输出检索说明并等待用户选品

推荐表格后输出：

- 搜索关键字。
- 覆盖平台。
- 检索结果总数和过滤后保留数量。
- 推荐度 4 星及以上商品列表。
- 价格、优惠券、月销和库存实时性的注意事项。
- 简短结论，例如最低价、性价比最高、销量较高的选择。

最后提示用户选择商品序号：

> 请输入您关注的商品序号（可多选，用逗号或空格分隔），我将为您获取购买链接。例如：`1, 3, 5`。

然后停止并等待用户输入，不要自动进入下一步。

### 第四步：根据用户选择获取购买链接

用户输入序号后，根据内部映射找到对应 `goodsId` 和 `sourceType`，逐个执行：

```bash
python3 scripts/price.py link --goodsId "{goodsId}" --sourceType {sourceType}
```

每次请求之间间隔约 0.5 秒，避免请求过快。

链接选择优先级：

1. 浏览器可直达的官方商品详情页，例如 `https://item.jd.com/<id>.html`、`https://detail.tmall.com/item.htm?id=<id>`、`https://item.taobao.com/item.htm?id=<id>`。
2. 如果接口只返回 `appUrl` / `schemaUrl` / 口令，先尝试把它解析或替换为上述商品详情页；不能解析时，明确标注“仅返回短链/口令，需用户在 App 内打开或按关键词复核”。
3. 复制口令或其他可用跳转信息只能作为辅助信息，不要把它称为“具体商品页链接”。

`u.jd.com`、`m.tb.cn`、`p.pinduoduo.com`、联盟短链、移动端短链、App schema 和口令在很多 PDF 阅读器、桌面浏览器或无登录环境中无法直接打开。若结果会被其他技能写入 PDF/Markdown 报告，必须优先提供直达详情页；拿不到时输出“待复核链接 + 精确检索关键词 + 平台 + 店铺名/店铺类型 + 缺失原因”，不要只给短链。

### 第五步：汇总输出最终结果

将用户选择的商品整理成最终表格：

| ID | 名称 | 平台 | 商铺 | 价格 | 链接/口令 |
| --- | --- | --- | --- | --- | --- |

链接按价格升序排列。若有浏览器可直达的商品详情页，优先输出详情页；若只有短链或口令，明确标注它不是可复核详情页，并附精确检索关键词。表格后给出简短购买建议和风险提示。

## 兼容命令

原 `taobao` skill 使用 `uv run scripts/main.py search/detail`。合并后默认不用 `main.py`，统一改用标准库脚本：

```bash
python3 scripts/price.py search --keyword "关键字" --sourceType 0 --pages 1 --format csv
python3 scripts/price.py link --goodsId "商品ID" --sourceType 1
```

如果用户或旧流程提到 `source=10` 的 1688，需要转换为 `sourceType=22`。

## 使用说明

当用户问“你能干什么”“这个技能有什么用”“你能帮我买什么”时，简要说明：

> 我可以帮你在淘宝/天猫、京东、拼多多、抖音、快手、1688、苏宁、唯品会等平台搜索商品、比较价格、查看优惠，并在你选择商品后获取购买链接或口令。完整流程是：搜索商品 → 过滤推荐 → 你选商品 → 我获取购买链接。

## 注意事项

- 电商价格变化频繁，结果仅代表检索时点。
- 优惠券、库存、地区价、会员价可能因账号和地区不同而变化。
- 低价商品可能存在规格不符、配件误匹配、缺货、限购或非官方渠道风险。
- 下单前应再次核对商品规格、店铺、售后和优惠是否可用。
